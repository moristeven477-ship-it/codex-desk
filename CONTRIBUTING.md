# Contributing

Codex Desk is intentionally focused on managing the official Codex CLI on Ubuntu. Keep new features within that scope. Discuss large changes in an issue first.

1. Install Node.js 22.16+ and run `npm ci`.
2. Use `npm run dev` for the desktop application.
3. Keep protocol and filesystem logic in the Electron main process.
4. Run `npm run format:check`, `npm run typecheck`, `npm test` and `npm run test:e2e`.
5. For main/preload changes, also build a Linux package and run `node scripts/native-smoke.mjs`.

Use synthetic fixtures for screenshots and automated tests. Never commit Codex credentials, user-data folders, real conversation histories, or `.env` files. Both English and Chinese labels are required for new user-facing controls.

Runtime protocol changes should be checked against schema generated by the installed CLI. Focus tests on meaningful behavior: event ordering, approvals, process failures, filesystem boundaries, and visible workflows.

The original icon is `public/icon.svg`; `node scripts/icon.mjs` rasterizes it with a local Chrome installation. The checked-in PNG allows builds without Chrome.
